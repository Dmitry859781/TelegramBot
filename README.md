# Zametochki_bot

**Zametochki_bot** — это Telegram-бот, созданный для напоминаний и других полезных функций. Он позволяет создавать, управлять и получать уведомления о событиях.

---

## Функции

- `/start` — начать взаимодействие с ботом.
- `/help` — получить список команд или помощь по конкретной команде.
- `/about` — информация о боте.
- `/author` — информация об авторе.
- `/addNote` — добавить новую заметку.
- `/editNote` — отредактировать существующую заметку.
- `/showNote` — посмотреть содержимое заметки.
- `/removeNote` — удалить заметку.
- `/AddOnceReminderCommand` — Добавить разовое напоминание.
- `/AddRecurringReminderCommand` — Добавить повторяющееся напоминание.
- `/EditOnceReminderCommand` — Редактировать разовое напоминание.
- `/EditRecurringReminderCommand` — Редактировать повторяющееся напоминание.
- `/RemoveReminderCommand` — Удалить напоминание.
- `/ShowReminderCommand` — Показать напоминание.
- `/SetOrEditTimezoneCommand` — Установить или изменить ваш часовой пояс.
- `/cancel` — отменить текущую операцию и вернуться в главное меню.

---

## Архитектура

- CommandRegistry — регистрирует и управляет командами.
- BotFSM — управляет состояниями пользователей (Singleton).
- NoteService — управляет заметками в базе данных (Singleton).
- ReminderService - управляет напоминаниями в базе данных (Singleton).
- UserTimezoneService - управляет временной зоной пользователя в базе данных (Singleton).
- TelegramBot — основной класс бота, обрабатывает входящие сообщения.

---

## Технологии

- **Java 17**
- **Maven** — для управления зависимостями и сборки.
- **TelegramBots API** — для взаимодействия с Telegram Bot API.
- **JUnit 5 & Mockito** — для модульного тестирования.
- **SLF4J** (опционально) — для логирования.
- **SQLite** (опционально) — для хранения данных.
